# Güvenlik Politikası

WebPwn'i yalnızca sahibi olduğunuz veya test etmek için açıkça yetkilendirildiğiniz sistemlerde kullanın.

## Güvenli kullanım

- Önce yerel demo sunucusu üzerinde deneyin.
- Üretim sistemlerinde yazılı izin alın ve düşük istek bütçesi kullanın.
- Aracı üçüncü taraf sistemlere karşı izinsiz çalıştırmayın.
- Raporlarda hassas veri bulunabileceğini varsayın; paylaşmadan önce temizleyin.

## Güvenlik açığı bildirimi

WebPwn'in kendisinde güvenlik sorunu bulursanız, herkese açık şekilde istismar ayrıntısı yayımlamadan önce depo sahibine özel bir bildirim kanalı üzerinden iletin.
